YOYO成长档案 V4 PWA
- 首页重新设计为移动端仪表盘
- 头像淡入、爪印漂浮、卡片依次上浮、页面切换动画
- 首页只预览最近3条体重和最近健康记录
- 完整体重历史仍保留
- 猫砂、体温、疫苗、驱虫功能保留
- PWA 安装与离线缓存保留

使用：
1. 完整解压。
2. 将 YOYO 照片命名为 yoyo.png 放到 images 文件夹。
3. 本地可双击 index.html 预览；PWA 安装/离线功能需部署到 HTTPS（如 GitHub Pages）。
4. 如果替换 GitHub Pages 旧版本，请上传本包所有文件，确保 service-worker.js 也一起更新。
